### Access Types:
- **Console access**: Connecting to the device directly using a console cable.
- **Telnet**: Establishing a remote connection to the device over a network using Telnet protocol <font color="#953734">(Not secure)</font>.
- **SSH (Secure Shell)**: Like Telnet but provides secure encrypted communication <font color="#953734">(secure)</font>.
- **SNMP (Simple Network Management Protocol)**: Used for monitoring and managing network devices remotely.
- **IOS (Internetwork Operating System)**: IOS provides the core framework and features that allow users to configure, manage, and control device operations.
- **Configuration**: Allowing administrators to configure various aspects of the device.
- **Control plane**: Handling protocols and processes responsible for device management.
- **Data plane**: Processing and forwarding network traffic.
- **Security**: Providing features for securing the device such as <u>(ACLs)</u> , <u>(VPNs)</u> , <u>(IPS)</u>.

### Levels
1. **User EXEC**: This is the default mode when you access the router. It provides <font color="#e36c09">limited access</font> to basic monitoring commands. <u>The prompt in this mode typically ends with a ">" symbol.</u>
2. **Privileged EXEC**: It offers greater control and allows you to perform tasks such as configuring <font color="#e36c09">interfaces</font>, viewing <font color="#e36c09">system information</font>, and executing <font color="#e36c09">privileged commands</font>. <u>The prompt in this mode usually ends with a "#" symbol.</u>
3. **Global Configuration**: This mode enables you to make changes to the device's global configuration parameters, such as setting the <font color="#e36c09">hostname</font>, configuring <font color="#e36c09">routing protocols</font>, establishing security parameters, and defining interface-level configurations. <u>The prompt in this mode typically ends with "(config)#".</u>
4. **Interface Configuration**: Configure individual interfaces on the router, It enables you to set specific <font color="#e36c09">parameters</font> for a particular interface, such as <font color="#e36c09">IP address</font>, <font color="#e36c09">subnet mask</font>, bandwidth settings, and other interface-related configurations. <u>The prompt in this mode typically reflects the name of the interface being configured.</u>
5. **Line Configuration**: This mode allows you to configure settings for different types of lines on the router, such as <font color="#e36c09">console ports</font>, virtual terminal lines <font color="#e36c09">(VTY)</font>, or <font color="#e36c09">auxiliary</font> ports. <u>It enables you to modify parameters like login authentication, timeouts, and linespecific configurations.</u>
6. **ROM Monitor**: ROM Monitor Mode is a low level mode used for <font color="#e36c09">troubleshooting</font> and <font color="#e36c09">recovering</font> the device. It provides access to the device's bootstrap program, allowing you to perform tasks like <font color="#e36c09">password recovery</font>, <font color="#e36c09">software upgrades</font>, or <font color="#e36c09">booting</font> from different sources.

### Definitions #defs
#### Number system
- Decimal System (Base 10).
- Binary System (Base 2).
- Octal System (Base 8).
- Hexadecimal System (Base 16).

#### MAC Address
- **A MAC address** <font color="#7030a0">(Media Access Control address)</font> is a unique identifier assigned to a network interface card (NIC) or network adapter. It is used to <font color="#f79646">identify devices on a local network</font>, like Ethernet or Wi-Fi, for communication between devices.
- **Format**: A MAC address is typically represented as a <font color="#f79646">12-digit hexadecimal</font> number, often shown in this format: XX:XX:XX:XX:XX.
- **Uniqueness**: Each MAC address is supposed to be <font color="#f79646">unique</font> to the device and is usually <u>hardcoded into the network interface by the manufacturer</u>.

#### IP Address
- **An IP Address** <font color="#7030a0">(Internet Protocol Address)</font> is a <font color="#f79646">unique</font> identifier assigned to each device connected to a network, used to <font color="#f79646">facilitate communication</font> and the <font color="#f79646">routing of data</font> between devices over the internet or local networks.
- **Types of IP Addresses**: 
	1. IPv4 (Internet Protocol version 4).
	2. IPv6 (Internet Protocol version 6).
