| CLI is a way to interact with a computer by typing text commands. Instead of using a mouse or touch screen, you enter instructions (commands) in a "terminal" or "console" window. These commands let you perform specific tasks like opening files, moving data, or installing software. CLI requires knowledge of specific commands and how to use them, so it’s more suited for experienced users. | GUI is an interface that relies on graphics like windows, icons, and buttons. Users interact with the computer by clicking or dragging elements using a mouse or touch screen. There’s no need to type anything or know special commands, as everything is displayed visually and is easy to access. GUI is user-friendly and ideal for general users. |

|                       | CLI                                     | GUI                                          |

| Learning Curve        | requires memorizing commands and syntax | Easier; visually intuitive and user-friendly |
| Flexibility and Speed | High; supports automation and scripting | Great for multimedia and visual tasks        |

### Access Types:
- **Console access**: Connecting to the device directly using a console cable.
- **Telnet**: Establishing a remote connection to the device over a network using Telnet protocol <font color="#953734">(Not secure)</font>.
- **SSH (Secure Shell)**: Like Telnet but provides secure encrypted communication <font color="#953734">(secure)</font>.
- **SNMP (Simple Network Management Protocol)**: Used for monitoring and managing network devices remotely.
- **IOS (Internetwork Operating System)**: IOS provides the core framework and features that allow users to configure, manage, and control device operations.
- **Configuration**: Allowing administrators to configure various aspects of the device.
