
| <center>CLI (Command-Line Interface)</center>                                                                                                                                                                                                                                                                                                                                                         | <center>GUI (Graphical User Interface</center>                                                                                                                                                                                                                                                                                                         |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| CLI is a way to interact with a computer by typing text commands. Instead of using a mouse or touch screen, you enter instructions (commands) in a "terminal" or "console" window. These commands let you perform specific tasks like opening files, moving data, or installing software. CLI requires knowledge of specific commands and how to use them, so it’s more suited for experienced users. | GUI is an interface that relies on graphics like windows, icons, and buttons. Users interact with the computer by clicking or dragging elements using a mouse or touch screen. There’s no need to type anything or know special commands, as everything is displayed visually and is easy to access. GUI is user-friendly and ideal for general users. |
