### Access Types:
- **Console access**: Connecting to the device directly using a console cable.
- **Telnet**: Establishing a remote connection to the device over a network using Telnet protocol <font color="#953734">(Not secure)</font>.
- **SSH (Secure Shell)**: Like Telnet but provides secure encrypted communication <font color="#953734">(secure)</font>.
- **SNMP (Simple Network Management Protocol)**: Used for monitoring and managing network devices remotely.
- **IOS (Internetwork Operating System)**: IOS provides the core framework and features that allow users to configure, manage, and control device operations.
- **Configuration**: Allowing administrators to configure various aspects of the device.
- **Control plane**: Handling protocols and processes responsible for device management.
- **Data plane**: Processing and forwarding network traffic.
- **Security**: Providing features for securing the device such as <u>(ACLs)</u> , <u>(VPNs)</u> , <u>(IPS)</u>.

### Levels
1. **User EXEC**: This is the default mode when you access the router. It provides limited access to basic monitoring commands. <u>The prompt in this mode typically ends with a ">" symbol.</u>
2. **Privileged EXEC**: It offers greater control and allows you to perform tasks such as configuring interfaces, viewing system information, and executing privileged commands. <u>The prompt in this mode usually ends with a "#" symbol.</u>
3. **Global Configuration**: This mode enables you to make changes to the device's global configuration parameters, such as setting the hostname, configuring routing protocols, establishing security parameters, and defining interface-level configurations. <u>The prompt in this mode typically ends with "(config)#".</u>
